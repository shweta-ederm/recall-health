# RH KPI Dashboard

A UI prototype for the Recall Health KPI Dashboard - analytics and metrics visualization for dermatology practice management.

## Project Overview

This is a UI-only prototype web application designed to display key performance indicators (KPIs) and analytics for dermatology practices. The dashboard provides at-a-glance metrics on patient engagement, revenue, and operational performance.

## Features

- **KPI Overview**: Top-level metrics for patients ready for contact, average revenue per visit, and total potential revenue
- **Customizable Filters**: Filter by period, practice, locations, and providers
- **Metrics Dashboard**: Display of key business metrics with color-coded indicators
- **Analytics Charts**: Visual representation of revenue and appointment trends
- **Responsive Layout**: Clean, professional dashboard interface
- **Navigation**: Sidebar navigation with main sections and subsections

## Technology Stack

- HTML5
- CSS3 (with CSS Custom Properties)
- Vanilla JavaScript
- Chart.js for data visualization
